# Little H Cafe

A simple, responsive cafe website built with plain HTML, CSS and JavaScript.

## Features
- Responsive mobile and desktop design
- Cafe menu with category filters
- Add-to-basket ordering interface
- Quantity controls and automatic total
- Table reservation/booking form
- No frameworks or build tools required
- Ready for GitHub Pages

## Run locally
Open `index.html` in a browser.

## Put it on GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and this README.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save. GitHub will provide your website URL.

## Important
The ordering and booking forms are front-end demos. They do not send real orders or reservations anywhere yet. For a real cafe, connect them to a backend, database, email/form service, or ordering/reservation provider.
